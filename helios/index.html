We build in the open.

View on Github Explore the server

The Helios FHIR Server is our open-source implementation of the HL7® FHIR® standard, written in Rust for performance and built for clinical analytics at scale. It supports FHIR R4 through R6 in a single system, with complete FHIRPath and SQL-on-FHIR engines, and deploys anywhere from a laptop to a production cluster. It is free, MIT-licensed, and public on GitHub.
